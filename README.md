# Tiny Barrage · 小小炮火

一座小岛，两支小队，六辆小坦克。使用 Godot 4 制作的原创 **百战天虫式 2D 回合制炮击游戏**，两人共用一台电脑交替操作。

## 开始游戏

1. 使用 **Godot 4 标准版（本项目使用 4.7.2 验证）**打开 `project.godot`。
2. 按 **F5** 运行主场景，点击 **Start Skirmish**（或回车）。
3. Coral Crew 与 Mint Brigade 各有 3 辆、每辆 100 HP；消灭对方全部单位获胜。

本地开发/原生试玩使用 Godot **4.7.2**、Compatibility 渲染器。无需插件、账号、联网或额外素材下载。仓库交付源码，不包含引擎、导出模板或二进制包。

```bash
godot --path .
```

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | **A / D**（每回合移动额度有限） |
| 跳跃 | **W**（消耗部分移动额度） |
| 瞄准 | **鼠标**或 **方向键** |
| 蓄力 / 发射 | 按住 **Space / 鼠标左键**，松开发射 |
| 取消蓄力 | 鼠标右键 |
| 选择弹药 | **1 / 2 / 3** |
| 提前结束回合 | **Q** |
| 暂停 / 继续 | **Esc** |
| 帮助 | **H / F1** 或右下角 **?** |
| 新一局 | **R**（有确认提示） |
| 声音 / 全屏 | **M / F11** |

- **Shell**：无限量标准炮弹，直击与爆炸伤害。
- **Bouncer**：会反弹，2.6 秒引信；每队 2 枚，爆炸范围更大。
- **Split Shot**：飞至抛物线顶点分成 3 枚小炮弹；每队 2 枚。
- 每回合 **35 秒**，只能开火一次。发射后等待弹道、爆炸、地形和坦克全部稳定，再交接给对方。
- 有风、友军伤害、爆炸击退、坠落伤害和落水淘汰。抛物线点只预览前半段，不会替你计算命中。
- 失去窗口焦点自动暂停并取消蓄力，避免切换窗口时误发射。

## 实现

- **完整二维像素遮罩地形**，不是只有一条高度曲线：能炸出洞穴、坑洞和悬空结构。
- 从底部连通性判定支撑；被切断的土地块逐格下落至稳定，仍相连的洞顶不会无故塌掉。
- 地形拓扑使用遮罩；渲染与边缘碰撞共同使用连续三次重建的有符号距离场。地面、洞穴与新炸出的坑边均平滑抗锯齿，取消像素草丛和颗粒贴图。弹丸使用分段扫掠避免穿透薄壁。
- 固定步长坦克重力/移动、径向爆炸伤害与冲量、三种弹道、显式回合状态机。
- 全画面 **16:9 高清卡通美术**：原创平滑海岛插画、圆润渐变小坦克、精简 HUD、抗锯齿爆炸/水花与原创合成音效。
- 固定全场镜头保证所有单位和地形可见；窗口缩放保持比例。弹丸飞出顶部时显示指示标记。

### 文件结构

```text
scripts/game.gd       匹配状态、输入、弹道、单位物理、UI 与效果
scripts/terrain.gd    可破坏拓扑、连续碰撞、地形连通性和落块
shaders/terrain.gdshader  原生分辨率平滑地形、边缘抗锯齿与渐变材质
scripts/sound.gd      原创合成音效
assets/              原创 SVG 与字体（附许可证）
tests/               纯模拟回归测试与原生画面采集脚本
```

## 验证

```bash
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/test_terrain.gd
godot --headless --path . --script tests/tests_gameplay.gd
```

测试覆盖真实坑洞/悬空落块、碰撞边界、弹药/伤害/击退、三类弹道、回合交接、超时、死亡/胜负/平局、重新开局与中断恢复。`tests/capture_demo.gd` 使用真实游戏物理与发射流程采集演示，不替换真实地形或弹道。

原生可复现采集（使用真实 **1920×1080 SubViewport**，不放大截图；输出请放在仓库外）：

```bash
godot --path . --resolution 1280x720 --fixed-fps 30 --script tests/capture_demo.gd -- --capture-dir=/absolute/output/path
```

## 范围与许可

第一版本为 **本地双人热座**，不包含电脑 AI、联网、地图编辑器或存档。地图是同一双岛布局的确定性地形变化，不是无限地图生成器。地形拓扑网格为 3 个世界像素/格，但显示与边缘碰撞均为连续曲面，并非放大的像素贴图。断块仅做竖直落下，不旋转为刚体。
