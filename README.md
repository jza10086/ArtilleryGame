# 炮火争锋

GodotParty 原版协议的 1–8 人回合制炮击游戏。从正式主菜单创建原版轮换房间，在小游戏池选择炮火争锋；房间规则选择模式。

- **自由混战：2–8 人**，每人一辆 200 生命坦克，最后存活者获胜。
- **团队对抗：2、4、6、8 人**，按参赛顺序交替分为蓝红两队，分驻战场两侧。存活队获胜，全队共享名次；队友也会受到爆炸伤害。
- **单人测试：1 人**，三座静止靶标、无限弹药、不限时、射手无敌。可重置靶场或结束测试；靶标没有 AI，也不参与排名。

每回合 35 秒、90 点移动额度、一次开火。按住 A / D 或移动按钮连续移动；W / S 增加／减小角度，Q / E 减小／增加力度，滑条也可直接调整。左键从战场空白处按下并拖动，同时估算角度与力度：可见预览范围内让曲线经过鼠标，范围外让预览末端的切线指向鼠标，不再补偿不可见段的下坠；松开只结束瞄准，Space 或开火按钮才会发射。不可达目标仍受角度 5–175°、力度 10–100% 限制。1–8 快选前八种炮弹，弹药库选择全部 16 种炮弹。按键支持本地设置重绑定。Esc 使用框架菜单，菜单及弹药库打开时停止控制，联机计时继续。

倒计时位于顶部中央的原版主题面板，10 秒及以下数字变红；单人测试显示 ∞。下方箭头表示风吹向的方向，数值表示风力大小（0–38）；风支持 360°，水平和垂直分量共同作用于弹道。瞄准线为逐渐变细的连续曲线，最多显示发射后的前 0.6 秒，使用与实弹相同的风力、重力和黑洞引力；在地形、传送门或反弹障碍前停止，分裂弹只预览到分裂点，不预演后续子弹。坦克与补给在主机快照之间平滑显示，大幅位置跳变立即定位。

| 弹药 | 行为 | 多人初始数量 |

| 标准弹 | 单发中型爆破 | 无限 |
| 重型爆破 | 更大爆炸与深坑、较低初速 | 0 |
| 三重散射 | 三条略微分开的弹道 | 1 |
| 集束花火 | 最高点分为五枚子弹 | 0 |
| 跳弹 | 地表反弹，3 秒引信 | 0 |
| 钻地弹 | 入土后继续钻进，再于地下爆炸 | 0 |
| 造山弹 | 抬升地形形成掩体，低伤害 | 0 |
| 虹吸弹 | 伤害敌人并回复射手部分生命 | 0 |
| 滚地雷 | 触地后滚动，接近坦克或 1.5 秒后爆炸 | 0 |
| 空爆弹雨 | 最高点分为七枚向下散射的子弹 | 0 |
| 燃烧弹 | 落点持续燃烧三个全局回合，每回合 12 伤害 | 0 |
| 电磁脉冲 | 范围伤害，命中者下次移动额度减半，不挖坑 | 0 |
| 跃迁弹 | 将射手移至落点；占据或底部危险区拒绝传送 | 0 |
| 连锁震爆 | 从落点向两侧依次引爆五段震波 | 0 |
| 感应雷 | 六回合内，敌人进入 52 像素范围后引爆 | 0 |
| 护盾弹 | 爆心附近友军获得 60 护盾，上限 100；先吸收伤害 | 0 |

战场显示期间启用 8× 2D MSAA，退出后恢复原视口设置；坦克纹理使用线性过滤。地形渐变按每局初始化时的高度场固定在世界坐标上，炸坑或造山只改变轮廓，不移动渐变；重置靶场时才使用新地图的初始渐变。

地形为连续高度场：爆炸挖坑、造山抬升地表；不模拟洞穴和悬空块。较大落差造成坠落伤害，底部危险线淘汰坦克。超过每人八回合后进入决胜阶段，每回合全员损失 12 生命，防止无限跳过回合。

## 战场事件

事件由主机随种子生成位置并同步。这里的回合指每位玩家的一次行动；事件和地面火区的寿命按全局回合计数。事件外观依据官方实机截图：黑洞采用暗核、细蓝紫旋流与稀疏星尘；蓝橙传送门为暗心光圈；反弹障碍为洋红空心光环；×2／×3 增伤分别使用红色／橙色分段光圈。保持矢量几何与局部辉光，不显示常驻事件说明和回合标签。

- 黑洞每八回合出现一次，持续四回合。280 像素范围内弯曲弹道，18 像素核心吞噬炮弹。瞄准点使用同一引力计算。
- 空投补给在每个八回合周期的第 1、4、7 回合出现，缓慢落向地表。坦克接近或炮弹击中可领取，恢复最多 35 生命并随机增加两发特殊弹药；同一箱只能领取一次。
- 增伤标记在周期第 5 回合出现，持续四回合。常见 ×2 和较稀有的 ×3（20%，碰撞范围更小）只由首枚命中的炮弹领取；倍率取最高值，不连乘。子弹、后续燃烧和地雷继承倍率。
- 双向传送门在周期第 2 回合出现，持续四回合。蓝、橙两端配对，炮弹进任意一端后保留速度和增伤，从另一端继续飞行；跨地图的拖尾会断开。瞄准预览在入口处停止。
- 反弹障碍在周期第 3 回合出现，持续四回合。洋红光环按碰撞表面反射炮弹，不消耗炮弹；瞄准预览在光环处停止。
- 支援无人机在周期第 6 回合出现，保留三回合。射中后向距离无人机最近的存活敌人发射三枚小型弹雨炮弹，完成本次支援后消失。支援炮弹继续受风力、黑洞、传送与反弹影响，按激活者计伤害。
- 燃烧会伤及队友；感应雷只由敌人触发，爆炸仍有友伤。护盾不会阻止断线退出。补给不能复活已淘汰的玩家。

## 框架与实现

主机计算弹道、碰撞、地形、伤害、回合与排名；客户端仅发送带回合编号的逻辑操作，接收主机快照。离线参与者退出排名；团队输赢仍以剩余队员判断。框架负责准备门、结算门和主机断线结束会话。

- `game.tscn` / `game.gd`：正式入口、输入、HUD、PartyAPI 生命周期与同步。
- `battle.gd`：纯对局规则、弹道与地形。
- `tank_model.tscn` 是可单独编辑的侧视坦克。底盘贴坡，炮塔随车体安装，炮管独立俯仰和后坐，`Muzzle` 标记瞄准线的起点。`battle.gd` 定义安装点和炮管长度，实弹从同一位置发射。
- 受击显示红色负数（含护盾吸收），补给与虹吸回血显示绿色正数，按实际生效量显示。浮字上浮淡入 0.24 秒、停留 0.75 秒，再上浮淡出 0.42 秒；时长可在 Battlefield 的 Inspector 中调整。
- `battlefield.gd` 绘制地形、弹道和爆炸，并按玩家或队伍颜色显示坦克。多人对局的血量显示在坦克旁，瞄准与开火控件在自己的瞄准回合出现。
- `settings.gd` / `manifest.json`：房间模式和可开局人数。
- `prototype/`：保留的旧双人原型源码，不是正式入口。

美术与玩法概念参考 [ShellShock Live 官方介绍](https://www.shellshocklive.com/)，未使用其素材或源码。坦克使用 [Kenney Tanks](https://kenney.nl/assets/tanks) 的 CC0 侧视素材，保留原始高清 PNG，以 Sprite2D 区域拆分车体和炮塔，独立绑定炮管。素材与许可位于 `assets/kenney_tanks/`；战场和事件光效由 Godot 绘制。原型中的字体许可仍见 `prototype/assets/FONT_LICENSE.txt`。

F6 运行 `game.tscn` 可查看 1920×1080 构图；实际试射从大厅选择单人测试。验证命令与范围见 [TESTING.md](TESTING.md)。

音效沿用空白模板的 PartyGameAudio / PartyAudioCue：成功移动时播放连续发动机，开炮与 16 种命中音色按主机事件同步，子母弹分裂、子弹爆炸、跳弹、钻地、布雷与连锁震爆独立发声。音量沿用协议 SFX 设置，退出关闭作用域。音效可在 game.tscn 的 CombatAudio 节点和 audio/*.tres 中替换与调参；素材商用许可与逐文件来源见 [assets/audio/SOURCES.md](assets/audio/SOURCES.md)。

多人配给按完整轮次计算（所有存活玩家各行动一次）：初始仅标准弹无限、三重散射 1 发。第 3 轮全员获得同一种随机基础特殊弹 1 发（重型／散射／跳弹／造山／滚地雷／感应雷）；第 5 轮全员获得两种不同进阶弹各 1 发（钻地／虹吸／燃烧／EMP／跃迁／护盾）；第 7 轮起每两轮发放集束花火、空爆弹雨、连锁震爆各 1 发。只给仍在场玩家配给，所有人领取相同内容；补给箱仍可从全部特殊弹中随机抽两发，因此可以提前获得高级弹。单人测试仍全部无限。

房主可在小游戏设置的“初始特殊弹药”分组中，逐项设置 15 种特殊弹的开局数量（0–20 发）；适用于混战和团队赛，下次小游戏开局生效。标准弹固定无限，单人测试全部无限；阶段配给不变。团队赛每回合仅一人行动，按名单顺序轮换（初始交替分入两队），淘汰者跳过，并非整队同时行动。
